# Reserved names

Install only the real package. The other names are placeholders that carry no code, only a README pointing to the real package.

| Name | Registry | Purpose | Status |
|---|---|---|---|
| `@mercurifi` | npm | Org scope | created (free org) |
| `@mercurifi/sdk` | npm | The TypeScript package | published |
| `mercurifi` | npm | Placeholder | not reserved: needs an owner decision |
| `mercurifi-sdk` | npm | Placeholder | not reserved: needs an owner decision |
| `mercuri-sdk` | npm | Placeholder | not reserved: needs an owner decision |
| `mercurifi` | PyPI | The Python package | published |
| `mercurifi-sdk` | PyPI | Placeholder (PyPI normalises `_` and `.` to `-`) | not reserved: needs an owner decision |
| `mercuri-sdk` | PyPI | Placeholder (same normalisation) | not reserved: needs an owner decision |
