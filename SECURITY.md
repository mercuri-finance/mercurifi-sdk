# Security policy

Report a vulnerability privately, through the GitHub security advisory of the SDK repository once it exists. Do not open a public issue for it. Never post a private key, an API key or an RPC URL with a key in it, in a report or anywhere else.

Supported versions: the latest beta.

The threat model and what the caps do and do not protect are in [docs/security-model.md](docs/security-model.md).
