# Mercurifi Agent Accounts SDK repository — Claude

This public Git repository owns the Mercurifi Agent Accounts SDKs: `packages/typescript` (npm `@mercurifi/sdk`) and `packages/python` (PyPI `mercurifi`), the shared vectors in `fixtures/`, and the release workflows. The contracts are in the separate public repository mercuri-finance/mercuri-agent-contracts; the SDK's address books and code hashes must match its deployment records, and only an owner-approved record may change them. Keep the two packages in step: the same operations, checks and errors, proven by the shared vectors. Run `npm run format` (Prettier is the standard; CI checks it), `npm test && npm run typecheck` and `uv run pytest`, plus `node scripts/check-workflows.mjs` for any workflow change. Publishing happens only through `release-npm.yml` and `release-pypi.yml`, each behind the owner's environment approval; npm versions are staged and go public only after the owner's 2FA approval (`docs/releasing.md`). Every publish needs its own explicit owner approval. Before any commit, push, PR or issue: login, author, committer and push transport must all be `mercurifinance`, unsigned, with no AI `Co-authored-by` trailer. Keep the repository public-clean: no personal or company names, local paths, private repository names, internal hosts or keys. Never read `.env` or disclose key material; tests and examples never use a paid RPC provider.
